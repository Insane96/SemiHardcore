# Semi-Hardcore

<img src="https://cf.way2muchnoise.eu/versions/For%20MC_645287_all.svg" alt="Available for MC">

Semi-hardcore is a Minecraft mod that lets you set up player lives, in a way that when they run out of them, you can no longer play, like in a Hardcore world. This is basically Hardcore but if you had more than one life.  
There are also config options to alter the max health of players each time they die.

Players can be opted out of the lives and max health changes with the `/semihardcore <player> optout <true/false>` command.
